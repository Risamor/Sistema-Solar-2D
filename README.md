# Sistema Solar 2D Interactivo

Explora una representación ilustrada e interactiva del Sistema Solar. La aplicación muestra el Sol, los planetas y varias de sus lunas principales en una animación 2D, con información educativa para cada cuerpo celeste.

## Características

- Animación de las órbitas alrededor del Sol y de las lunas alrededor de sus planetas.
- Control para ajustar la velocidad y pausar o reanudar la animación.
- Zoom con la rueda del ratón y desplazamiento del sistema arrastrando el lienzo.
- Panel informativo al seleccionar un planeta o una luna, con descripción, características y datos curiosos.
- Ilustraciones dibujadas en un elemento HTML Canvas, sin imágenes externas ni dependencias.
- Diseño adaptable a pantallas pequeñas.

## Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador moderno.
3. Haz clic en un cuerpo celeste para consultar su información.

No se requiere instalación, servidor ni herramientas de compilación.

## Controles

| Acción | Control |
| --- | --- |
| Consultar información | Haz clic en un planeta o luna |
| Acercar o alejar | Usa la rueda del ratón |
| Desplazar la vista | Arrastra el lienzo |
| Cambiar velocidad | Mueve el control deslizante «Velocidad» |
| Pausar o reanudar | Pulsa el botón «Pausar» o «Reanudar» |
| Cerrar información | Pulsa el botón × del panel |

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Canvas API
